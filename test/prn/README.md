# Arquivos `.PRN`

Este diretório contém um arquivo de exemplo de estatística de elevação para
testes unitários do OpenHFTA. Os padrões usados pelo portal ficam em
`prns/`.

Use `EXEMPLO-20M.PRN` com a frequência `14.20 MHz` ou `20m`. O parser também
aceita cabeçalhos com bandas (`20m`) e com frequências (`14.20 MHz`).

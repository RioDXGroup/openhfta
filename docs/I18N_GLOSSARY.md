# OpenHFTA — glossário de terminologia

O OpenHFTA preserva a terminologia técnica do HFTA original. As traduções devem
manter o significado de análise de propagação, sem transformar os termos em
descrições genéricas de gráficos.

| Português (Brasil) | English | Español |
| --- | --- | --- |
| Padrão de elevação | Elevation pattern | Patrón de elevación |
| Traçado de raios | Ray trace | Trazado de rayos |
| Terreno em primeiro plano | Foreground terrain | Terreno en primer plano |
| Perfil do terreno | Terrain profile | Perfil del terreno |
| Ângulo de chegada (AoA) | Angle of Arrival (AoA) | Ángulo de llegada (AoA) |
| Condutividade do solo | Ground conductivity | Conductividad del suelo |
| Constante dielétrica do solo | Ground dielectric constant | Constante dieléctrica del suelo |
| Polarização horizontal | Horizontal polarization | Polarización horizontal |
| Reflexão | Reflection | Reflexión |
| Difração | Diffraction | Difracción |
| Reflexão + difração | Reflection + diffraction | Reflexión + difracción |
| Difração dupla | Double diffraction | Doble difracción |
| Pilha/arranjo empilhado | Stacked array | Arreglo apilado |

`.PRO`, `.PRN`, `PRO`, `FLAT.PRO`, `AoA` e `HFTA` são identificadores técnicos
e devem permanecer inalterados. “Ray trace” também permanece em inglês quando
for usado como título operacional do gráfico, seguindo o estilo do software
original; o texto explicativo pode ser traduzido.

Fonte de referência: [HFTA Operating Instructions v1.04 (ARRL)](https://www.arrl.org/files/file/Antenna%20Book%20Supplemental%20Files/24th%20Edition/HFTA.pdf).
